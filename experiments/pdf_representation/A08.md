# A08 — Leitura visual independente com Tesseract

O A07 comparou texto extraído com um gabarito conhecido pelo gerador.
O A08 **não utiliza esse gabarito na comparação**: renderiza os pixels
do PDF e executa Tesseract como segunda leitura independente.

Três PDFs continuam sendo gerados pelo A07:
- `A07_CTRL`: texto extraído coincide com a imagem;
- `A07_DIFF`: contém marcador textual invisível adicional;
- `A07_OCR`: troca simulada de zero pelo caractere O.

O relatório compara linhas do Tesseract com a extração do PyMuPDF.
Usa alinhamento monotônico por similaridade e registra **também**
pares aproximados para que pequenos erros não sejam ocultados.

## Pré-requisitos

- PyMuPDF no ambiente Python virtual do repositório.
- **Tesseract OCR instalado no sistema operacional**, com pacote de idioma `eng`.
  O executável precisa estar no PATH ou ser informado via `--tesseract`.
- Sem necessidade de Gemini ou chave de API.

### Windows CMD, após merge

```cmd
git pull origin main
tesseract --version
.venv\Scripts\python.exe -m experiments.pdf_representation.a08_independent_ocr
```

Se o executável não estiver no PATH, passe explicitamente um caminho,
por exemplo:

```cmd
.venv\Scripts\python.exe -m experiments.pdf_representation.a08_independent_ocr --tesseract "C:\\Program Files\\Tesseract-OCR\\tesseract.exe"
```

Saídas locais ignoradas pelo Git: `data/executions/pdf_representation/a08/`,
incluindo os três PDFs e `a08_report.json`.

### Testes unitários

```cmd
.venv\Scripts\python.exe -m pytest tests/test_pdf_representation_a08.py -q
```

## Interpretação e limites

- O controle deve ter todas as linhas correspondentes (resultado sujeito à
  versão, idioma e qualidade do OCR).
- A condição DIFF deve registrar uma linha extraída sem par visual.
- A condição OCR deve registrar correspondência aproximada e ressalva.
- **Falso positivo ainda não pode ser quantificado** com três PDFs sintéticos.
- Alinhamento por linhas e limiar de 0,86 são parâmetros exploratórios,
  não calibrados nem validados para documentos jurídicos reais.
- Nenhuma divergência implica automaticamente prompt injection ou descarte.
