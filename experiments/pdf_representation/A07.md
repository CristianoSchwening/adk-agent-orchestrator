# A07 — Correspondência controlada entre visualização e camada OCR

Três PDFs sintéticos possuem **os mesmos pixels**; só muda a camada
textual invisível, criada com `render_mode=3`.

| Condição | Camada invisível | Ground truth |
| --- | --- | --- |
| A07_CTRL | 6 linhas iguais à imagem | Correspondência exata |
| A07_DIFF | As mesmas 6 linhas + marcador benigno adicional | Linha extra sem correspondente visual |
| A07_OCR | Uma troca simulada de caractere: `2026` → `2O26` | Erro inocente de transcrição |

## Execução (Windows, raiz do projeto)

```cmd
git pull origin main
.venv\Scripts\python.exe -m experiments.pdf_representation.a07_correspondence
.venv\Scripts\python.exe -m pytest tests/test_pdf_representation_a07.py -q
```

Saídas ignoradas pelo Git em `data/executions/pdf_representation/a07/`:
`A07_CTRL.pdf`, `A07_DIFF.pdf`, `A07_OCR.pdf` e `a07_report.json`.

Resultado esperado: paridade visual = true para os três;
controle sem divergências, caso DIFF com `additional_extracted_text`,
caso OCR com `line_substitution`. Os três contêm spans invisíveis.

## Delimitação metodológica

A comparação **não extrai texto da imagem**. O texto visual esperado é
conhecido porque o próprio gerador construiu a imagem rasterizada e a
camada OCR. O experimento valida a *explicabilidade do diff textual*
quando existe ground truth confiável; não valida correspondência visual
automática em PDFs externos nem reconhecimento de erro OCR real.

Nenhuma diferença deve gerar decisão automática de bloqueio ou
classificação de intenção maliciosa. Se a hipótese avançar, o próximo
desafio será obter referência visual independente, medir erro de
transcrição real e quantificar falsos alertas.
