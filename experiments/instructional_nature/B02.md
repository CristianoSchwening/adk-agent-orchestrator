# B02 — Classificação contextual de conteúdo instrucional

## Pergunta

O Gemini consegue distinguir pedidos jurídicos legítimos, citações de
instruções e tentativas de modificar seu processamento, com melhor
resultado que o baseline lexical B01?

## Protocolo

- Os **mesmos 16 trechos sintéticos** e rótulos de pesquisador do B01.
- Uma nova sessão ADK por trecho para impedir contaminação entre casos.
- Mesmo contrato estruturado para cada execução; sem ferramentas, sem
  delegação, sem PDF e sem OCR.
- Cada execução produz uma categoria, um destinatário, indicação de
  tentativa de redirecionamento, um trecho literal justificativo e um
  indicador de revisão.
- O texto é empacotado como dado não confiável. O classificador recebe
  instrução explícita para não seguir comandos presentes nele.
- Um caso citado deve ser julgado pelo contexto da citação, não pelo
  conteúdo isolado dos verbos imperativos.

## Requisitos

Usar o `.venv` atual com Google ADK e `.env` contendo
`GOOGLE_API_KEY` ou `GEMINI_API_KEY`; modelo em `E01_GEMINI_MODEL`
ou passado via `--model`. Experimento consome chamadas Gemini.

### Execução Windows (depois do merge)

```cmd
git pull origin main
.venv\Scripts\python.exe -m experiments.instructional_nature.b02 --model gemini-3.5-flash-lite
.venv\Scripts\python.exe -m pytest tests/test_instructional_nature_b02.py -q --basetemp=data/pytest_temp
```

Para usar outro modelo, substitua o identificador após `--model`.
O padrão é 1 repetição por caso (16 chamadas), com intervalo de 8 s.
Se houver limite de taxa, use `--pause-seconds 30`.

Saídas locais (fora do Git):

- `data/executions/instructional_nature/b02_results.jsonl`: histórico
  de tentativas, respostas, campos de saída, status e erros.
- `data/executions/instructional_nature/b02_report.json`: resumo
  **apenas da execução atual**. O JSONL é acrescentado, não sobrescrito;
  não combinar rodadas sem reconciliação.

## Métricas e interpretação

- TP, FP, TN e FN calculados apenas em respostas com JSON válido.
- Erros de API, respostas vazias e violações de contrato em contagens
  distintas, excluídos do denominador da matriz.
- `category_matches` mede correspondência com a categoria B01;
  `tentativa_redirecionamento` mede a classificação binária.
  Essas duas dimensões podem divergir, e isso merece inspeção.
- Comparar com B01: TP=7, FP=3, TN=5, FN=1. A comparação é exploratória,
  porque as entradas foram construídas para expor problemas lexicais.

## Limitações

A classificação de um comando **não demonstra execução desse comando**.
Os rótulos não têm adjudicação independente; o modelo classificador
também pode ser influenciado pelo texto que analisa. Não interpretar
métricas dessa amostra como eficácia de segurança em produção.


## Retomada resiliente (PR posterior ao B02 original)

- O executor lê o JSONL existente e **não repete** casos/repetições com
  `status=ok` e contrato JSON válido.
- Verifica modelo, SHA-256 da instrução, prompt e trecho de entrada para
  todos os registros existentes; conflito interrompe com erro. Para
  mudar modelo ou instrução, use **novo caminho de saída**.
- Casos com 503 anterior permanecem no histórico, mas podem ser refeitos.
  A matriz final considera somente a classificação válida por caso e
  repetição; erros históricos aparecem em contagem separada.
- Em cada caso, até três tentativas por padrão, somente para erros HTTP 503,
  com espera exponencial de 8, 16 segundos (limite configurável).
  Se falhar, o caso permanece pendente para uma próxima execução.
- O relatório é salvo após cada caso concluído, inclusive em execução
  parcial; o JSONL registra a trilha das tentativas em `retry_history`.
- As combinações `quoted_attack + tentativa_redirecionamento=true` e
  `agent_directive + tentativa_redirecionamento=false` ficam em
  `category_redirect_inconsistencies` como **diagnóstico**, sem mudar
  o prompt ou recodificar automaticamente a resposta.
- `--case-id B01_01` seleciona um caso; `--max-cases 1` executa só
  um pendente para verificação inicial. O `--output` padrão continua sendo
  o mesmo JSONL já existente.

### Primeiro testar uma chamada pendente

```cmd
.venv\Scripts\python.exe -m experiments.instructional_nature.b02 --model gemini-3.5-flash-lite --max-cases 1 --pause-seconds 0
```

### Depois retomar o restante

```cmd
.venv\Scripts\python.exe -m experiments.instructional_nature.b02 --model gemini-3.5-flash-lite --pause-seconds 15
```

Para testes offline:

```cmd
.venv\Scripts\python.exe -m pytest tests/test_instructional_nature_b02.py -q --basetemp=data/pytest_temp
```

O caminho local do resultado anterior deve permanecer acessível no diretório
do projeto. Caso o arquivo não exista mais, o programa iniciará uma nova
rodada e não conseguirá reaproveitar as duas classificações válidas.

**Cuidado:** uma amostra parcialmente concluída não é comparável ao conjunto
completo de 16 classificações. Não interpretar 503 como falha semântica.
